# Privacy policy: Manoj Explains uploader

Last updated: 20 November 2026

"Manoj Explains uploader" is a private app used only by the owner of the YouTube channel Manoj Explains
(@ManojExplainsMovies) to manage his own channel.

**What it accesses.** With the owner's permission (Google OAuth), it uses the YouTube Data API to upload the owner's
videos, set their titles, descriptions, thumbnails, privacy and publishing times, manage the channel's playlists and
read the channel's own video statistics.

**Whose data.** Only the owner's own channel. It does not ask anyone else to sign in and does not collect, store, sell
or share any personal data of viewers or of any other person.

**How access is kept.** The permission key is stored as a private setting in the owner's own cloud work environment,
never published, and used only to call Google's APIs for the purposes above. The owner can withdraw it at any time at
https://myaccount.google.com/permissions.

**Google API Services.** The app's use of information received from Google APIs follows the Google API Services User
Data Policy, including its Limited Use requirements.

**Contact.** Through the channel's About page on YouTube.
