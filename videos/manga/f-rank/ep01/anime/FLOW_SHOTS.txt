F-RANK TEA SELLER, EPISODE 1: GOOGLE FLOW SHOT LIST

HOW TO MAKE EACH SHOT (about 1 minute per shot)
1. Open labs.google/flow and start a new project called 'F-Rank Ep1'.
2. Choose 'Frames to Video'. Upload the start frame (the picture named in the list, from the 'keyframes' folder next to this document).
3. Paste the prompt. Model: Veo 3.1 Fast (best). If credits run low, use Veo 3.1 Lite. Aspect ratio 16:9. Length as listed.
4. Generate. If the face changes or the action is wrong, generate once more.
5. Download the video (720p is enough) and name it with the shot number, e.g. S09.mp4. For a second take: S09b.mp4.
6. Upload the downloaded videos on the private upload page Claude sends you (or put them in the 'clips' folder next to this document).

Credits: about 20 per shot with Veo 3.1 Fast (10 with Lite). 20 shots plus a few retakes = about 500 credits.
